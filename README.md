# ProxyFlow Demo

A modern proxy-themed landing page built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Files

- `index.html` — page structure
- `styles.css` — visual styling and layout
- `script.js` — form behavior

## Notes

This is a front-end concept for a proxy brand and does not include a real backend proxy server.
